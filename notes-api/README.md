
# Notes REST API

Проект по дисциплине «Технологии программирования».

## Описание проекта

Notes REST API — серверное приложение для управления заметками.

Пользователь может создавать, просматривать, редактировать и удалять заметки.

Приложение реализовано без графического интерфейса.
Для взаимодействия с сервером используются HTTP-запросы.

## Используемые технологии

- Python 3.13
- Flask
- Flask-SQLAlchemy
- SQLite
- Postman

## Возможности приложения

1. Создание новой заметки.
2. Получение списка всех заметок.
3. Получение отдельной заметки по ID.
4. Редактирование заметки.
5. Удаление заметки.
6. Проверка корректности входных данных.
7. Обработка ошибок 400 и 404.

## API

| Метод | Адрес | Описание |
|---|---|---|
| GET | /notes | Получить все заметки |
| GET | /notes/1 | Получить заметку по ID |
| POST | /notes | Создать заметку |
| PUT | /notes/1 | Изменить заметку |
| DELETE | /notes/1 | Удалить заметку |

## Пример создания заметки

Метод: POST

Адрес: http://127.0.0.1:5000/notes

JSON:

{
  "title": "Моя заметка",
  "content": "Изучение Python и Flask"
}

При успешном создании сервер возвращает статус 201 Created.

## База данных

Для хранения заметок используется SQLite.

Таблица note содержит три поля:

- id — уникальный идентификатор заметки;
- title — название заметки;
- content — текст заметки.

База данных создаётся автоматически при первом запуске приложения.

## Запуск проекта

1. Установить Python 3.13.

2. Создать виртуальное окружение:

   python -m venv .venv

3. Установить зависимости:

   .venv\Scripts\python.exe -m pip install -r requirements.txt

4. Запустить сервер:

   .venv\Scripts\python.exe app.py

5. Открыть адрес:

   http://127.0.0.1:5000/notes

## Тестирование

Для тестирования используется Postman.

Через Postman можно отправлять GET, POST, PUT и DELETE запросы и проверять ответы сервера.

## Обработка ошибок

- 400 Bad Request — неправильные входные данные.
- 404 Not Found — заметка не найдена.
- 200 OK — успешное получение, изменение или удаление.
- 201 Created — успешное создание заметки.
